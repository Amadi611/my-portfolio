Amadi Navodya — Developer Portfolio 🚀
A modern, fully responsive personal portfolio website built with **HTML, CSS, JavaScript, and PHP** to showcase my skills, projects, academic journey, and experience as an **IT undergraduate**.

| Feature         | Details                                                                                  |
| --------------- | ---------------------------------------------------------------------------------------- |
| Design          | Dark glass morphism UI · Modern gradient theme · Responsive layout                        |
| Animations      | Typing animation · Scroll reveal effects · Skill progress animation · Smooth transitions |
| Navigation      | Sticky navigation · Active section highlight · Mobile responsive menu                    |
| Projects        | Interactive project cards showcasing Web, Mobile, and Software Development projects      |

🖥️ Running Locally with XAMPP
Step 1 — Install XAMPP
Download and install XAMPP from: https://www.apachefriends.org

Step 2 — Copy the Project
Place the portfolio folder inside the XAMPP web root:

Windows
C:\xampp\htdocs\portfolio\

Step 3 — Start Apache
Open XAMPP Control Panel and start: Apache

Step 4 — Open Website
